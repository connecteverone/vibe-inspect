### US-003: Show mobile device name + device ID in desktop device list
Status: in_progress
Depends on: None

Description:
As a desktop user, I want connected devices to show a clear mobile device name and device ID so I can manage them.

Acceptance Criteria:
- [ ] Mobile sends a device name plus device ID (client_id) for client_name or a new dedicated field
- [ ] Desktop device list displays '<device name> · <device id>' and keeps existing actions (block/kick/forget)
- [ ] Example: device appears as 'iOS · 8f3a1b' with last seen time
- [ ] Negative case: if device name is empty, desktop shows 'Unknown · <device id>' and still allows unbind
