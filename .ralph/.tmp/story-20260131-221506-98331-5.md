### US-004: Add terminal session labels and rename synchronization
Status: in_progress
Depends on: None

Description:
As a user, I want to rename terminal sessions and have the name synced between mobile and desktop.

Acceptance Criteria:
- [ ] Terminal session payloads include a label field in list/status responses
- [ ] Add a terminal rename action that updates desktop session metadata and syncs to mobile storage
- [ ] Example: rename session to 'Deploy logs' on mobile and the desktop list shows the same label within 5 seconds
- [ ] Negative case: renaming to an empty string is rejected with a user-friendly error and no changes applied
