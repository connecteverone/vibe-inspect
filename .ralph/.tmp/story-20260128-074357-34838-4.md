### US-012: AI insight summaries for errors
Status: in_progress
Depends on: US-006

Description:
As a user, I want AI-generated insights on errors to speed up verification.

Acceptance Criteria:
- [ ] Trigger AI analysis for API and terminal errors
- [ ] Display AI summary in timeline and tool context
- [ ] Example: missing field error highlights the missing key
- [ ] Negative case: AI service unavailable shows a fallback message without blocking
