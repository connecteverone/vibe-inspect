### US-002: Desktop agent command channel and protocol
Status: in_progress
Depends on: US-001

Description:
As a user, I want the desktop agent to accept commands from mobile and return results.

Acceptance Criteria:
- [ ] Define a message schema for request/response and error payloads
- [ ] Expose a local command handler in the agent for API, terminal, and VNC actions
- [ ] Example: mobile sends a ping command and receives a structured pong response
- [ ] Negative case: unknown command returns a standardized error payload
