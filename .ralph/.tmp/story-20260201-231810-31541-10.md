### US-010: Desktop agent proxy to terminald
Status: in_progress
Depends on: US-006, US-003

Description:
As a mobile/desktop client, I want the desktop agent to proxy terminald while keeping existing payload schemas intact.

Acceptance Criteria:
- [ ] Desktop agent no longer owns PTY; it uses a terminald WS client for start/poll/input/resize/rename/stop
- [ ] Proxy preserves existing payload shape for mobile/desktop UI compatibility
- [ ] Agent can auto-start terminald when unreachable (configurable)
- [ ] Example: start a session via mobile, restart desktop agent, and attach continues with same session_id
- [ ] Negative: if terminald is unreachable, agent returns `connection_failed`
