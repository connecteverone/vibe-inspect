### US-002: Expose host_name from desktop identity and use it for agent display
Status: in_progress
Depends on: None

Description:
As a user, I want the PC agent to be identified by host name or device ID rather than IP:port.

Acceptance Criteria:
- [ ] Desktop identity response includes host_name (and is stored in pairing status as needed)
- [ ] Mobile stores host_name and uses it in agent display label priority
- [ ] Example: after QR pairing, the agent label shows 'MyMacBook' instead of '192.168.1.10:8899'
- [ ] Negative case: if host_name is missing, the label falls back to device_id instead of IP:port
