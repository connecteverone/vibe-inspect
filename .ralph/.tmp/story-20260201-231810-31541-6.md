### US-006: Attach/poll/input streaming + compatibility payloads
Status: in_progress
Depends on: US-005

Description:
As a client, I want attach/poll/input so I can stream output and send input while keeping payload compatibility.

Acceptance Criteria:
- [ ] Implement `attach`, `detach`, `poll`, and `input` actions with the specified envelope
- [ ] Attach adds a subscription and immediately emits a terminal_payload event with output since `since`
- [ ] `poll` returns terminal_payload with output since `since` and notifications since `notify_since`
- [ ] Example: `input` of "ls -la\n" results in output chunks with incremented seq
- [ ] Negative: providing both `data` and `data_b64` yields `invalid_request`
