### US-008: Backpressure handling + stream pause/resume + subscription limits
Status: in_progress
Depends on: US-006

Description:
As a server, I need bounded queues and backpressure so slow consumers do not cause memory growth.

Acceptance Criteria:
- [ ] Per-connection send queue is bounded by bytes; exceeding triggers `stream_paused`
- [ ] On backpressure, drop intermediate payloads and send a snapshot with `truncated: true`
- [ ] Emit `stream_resumed` when queue falls below low-water mark
- [ ] Example: a slow client triggers `stream_paused` and later receives a snapshot before resuming
- [ ] Negative: attaching more than 4 sessions on one socket returns `state_locked`
