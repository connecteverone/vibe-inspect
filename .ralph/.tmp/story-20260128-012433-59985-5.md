### US-007: Command Bar intent parsing and routing
Status: in_progress
Depends on: US-006

Description:
As a user, I want a single command bar to trigger API, terminal, AI, or VNC actions.

Acceptance Criteria:
- [ ] Command input accepts natural language and structured commands
- [ ] Route recognized intents to the correct tool and create a timeline event
- [ ] Example: `POST /login` opens API Explorer with method and URL prefilled
- [ ] Negative case: ambiguous command prompts the user to choose a tool
