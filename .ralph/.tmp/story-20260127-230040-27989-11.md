### US-003: Pairing flow with QR token and shared secret
Status: in_progress
Depends on: US-002

Description:
As a user, I want to pair my mobile app with my desktop agent securely.

Acceptance Criteria:
- [ ] Desktop agent generates a short-lived pairing token and QR code
- [ ] Mobile scans QR and confirms a shared secret before saving the connection
- [ ] Example: valid token + correct secret results in a connected state
- [ ] Negative case: expired token is rejected with a retry prompt
