### US-009: Session summary persistence and idle cleanup
Status: in_progress
Depends on: US-005

Description:
As a client, I want session summaries persisted so I can list sessions after daemon restart.

Acceptance Criteria:
- [ ] Persist session summaries to JSON with atomic write (tmp + fsync + rename)
- [ ] On startup, load summaries and mark stale entries as exited
- [ ] Idle sessions are cleaned after the configured TTL, with warning lead time
- [ ] Example: restart terminald and `list` shows previous sessions with status exited
- [ ] Negative: corrupted summaries file is ignored with a warning and does not crash
