### US-004: terminald WebSocket server + auth handshake
Status: in_progress
Depends on: US-003

Description:
As a client, I want a stable WebSocket server that authenticates and advertises server capabilities before I send commands.

Acceptance Criteria:
- [ ] terminald listens on localhost (default ws://127.0.0.1:7078/ws) and rejects non-localhost connections
- [ ] Server requires `auth` within 3 seconds and responds with server_info (version, server_time, capabilities)
- [ ] Major protocol version mismatch returns an error and closes the socket
- [ ] Example: valid token yields `ok: true` auth response with server_info
- [ ] Negative: missing or invalid token yields `invalid_auth` and connection close
