### US-005: Implement list/start/stop/rename/resize/keepalive actions
Status: in_progress
Depends on: US-002, US-004

Description:
As a client, I want core session management actions so I can create and manage terminal sessions via terminald.

Acceptance Criteria:
- [ ] Implement `list`, `start`, `stop`, `rename`, `resize`, and `keepalive` actions per the protocol
- [ ] `start` returns session_id and initial terminal_payload; `list` returns session summaries
- [ ] `rename` and `resize` are idempotent when unchanged
- [ ] Example: `start` with label "" and default size returns a running session with auto-generated label
- [ ] Negative: `resize` with cols < 10 or rows < 4 returns `invalid_size`
