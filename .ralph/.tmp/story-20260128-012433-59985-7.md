### US-008: API Explorer via desktop agent
Status: in_progress
Depends on: US-002, US-006

Description:
As a user, I want to run API requests on the desktop agent and inspect structured responses on mobile.

Acceptance Criteria:
- [ ] Send API request details to the agent and receive structured response payload
- [ ] Render response status, latency, headers, and JSON tree on mobile
- [ ] Example: response diff highlights changed fields from previous run
- [ ] Negative case: invalid JSON body prevents request with validation message
