### US-003: Discovery file creation and config overrides
Status: in_progress
Depends on: US-001

Description:
As a client, I want a discovery file to locate terminald and authenticate without manual configuration.

Acceptance Criteria:
- [ ] terminald writes a discovery file at OS config dir with fields ws_url, token, version, pid, created_at, capabilities
- [ ] Discovery file write is atomic and file permissions are user-only
- [ ] CLI honors overrides: `VIBE_CTL_ENDPOINT`, `VIBE_CTL_TOKEN`, `VIBE_CTL_CONFIG`
- [ ] Example: setting `VIBE_CTL_CONFIG` to a temp file allows vibe-ctl to connect using that endpoint
- [ ] Negative: unreadable config path returns `connection_failed` without crashing
