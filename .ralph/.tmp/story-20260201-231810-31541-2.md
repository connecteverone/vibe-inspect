### US-002: Extract terminal session core into terminal_core
Status: in_progress
Depends on: US-001

Description:
As a developer, I want session lifecycle, buffering, and payload building centralized so both terminald and the desktop agent use identical logic.

Acceptance Criteria:
- [ ] Move PTY lifecycle, buffer management, vt100 parsing, and payload building from `desktop/src/terminal.rs` into `terminal_core`
- [ ] Desktop agent code uses terminal_core functions and preserves payload schema compatibility
- [ ] Example: existing desktop terminal start/poll responses match the current payload fields and values
- [ ] Negative: missing session_id in a session-scoped call returns `missing_session` error
