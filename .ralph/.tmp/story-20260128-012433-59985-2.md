### US-004: Cloudflared tunnel integration
Status: in_progress
Depends on: US-003

Description:
As a user, I want mobile and desktop to connect over the internet via a tunnel.

Acceptance Criteria:
- [ ] Desktop agent starts a cloudflared tunnel and exposes a connection URL
- [ ] Mobile stores the tunnel URL as part of the connection record
- [ ] Example: remote connection succeeds when mobile is off the local network
- [ ] Negative case: tunnel startup failure is shown with a clear remediation message
