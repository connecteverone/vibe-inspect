### US-006: Enable terminal session operation from desktop UI
Status: in_progress
Depends on: US-005

Description:
As a desktop user, I want to open a terminal session and interact with it directly from the desktop UI.

Acceptance Criteria:
- [ ] Desktop UI provides a terminal session detail view with live output and input support (WebSocket or polling)
- [ ] Desktop UI supports resize and stop actions consistent with mobile behavior
- [ ] Example: open a session, run 'ls', and see output update live
- [ ] Negative case: if the session is missing or ended, the UI shows a non-blocking error and disables input
