### US-011: vibe-ctl CLI core commands
Status: in_progress
Depends on: US-003, US-004

Description:
As a user, I want a tmux-like CLI to list and manage sessions without attaching.

Acceptance Criteria:
- [ ] Implement commands: `ls`, `new`, `send`, `resize`, `rename`, `stop` with documented flags
- [ ] Global overrides: `--endpoint`, `--token`, `--config`, and `--json` for `ls`
- [ ] `new` supports name/cwd/cols/rows/env; `send` supports `--file`
- [ ] Example: `vibe-ctl ls --json` prints machine-readable JSON and exits 0
- [ ] Negative: `vibe-ctl new --cols 5` returns `invalid_size` and exits non-zero
