### US-005: Local data storage for sessions and events
Status: in_progress
Depends on: US-001

Description:
As a user, I want my timeline and tool history stored locally on mobile.

Acceptance Criteria:
- [ ] Persist core entities in local storage with a defined schema
- [ ] Install storage dependencies with explicit commands (example: `flutter pub add sqflite` and `flutter pub add flutter_secure_storage`)
- [ ] Example: timeline events persist after app restart
- [ ] Negative case: storage initialization failure shows a blocking error state
